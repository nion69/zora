Installation & Setup Guide

Follow these simple steps to deploy Zora AI on your Windows workstation.

1
System Requirements

Ensure your environment meets the minimum specifications:

  • Windows 10 or Windows 11 (64-bit)
  • Python 3.10, 3.11, or 3.12 installed with PATH enabled
  • Working Microphone and Speakers / Headphones
  • Active Internet connection for realtime WebRTC audio
2
Install via PyPI

Open PowerShell or Command Prompt as Administrator and run:

pip install --upgrade zoraai
3
Initialize & Register License

Start the background daemon. If launching for the first time, you will be prompted for your license key:

zora start
4
Test Audio Stream & Microphone

Verify live voice conversation and microphone levels:

zora console
5
Uninstallation

If you need to completely remove Zora AI, use the built-in clean uninstaller:

zora uninstall

Command-Line Interface (CLI)

Zora AI is controlled directly from your terminal using the global zora executable:

zora start

Launches the background voice assistant process. Runs silently in your system tray without interrupting other applications.

zora console

Launches an interactive foreground audio terminal. Displays real-time voice decibel levels, speech detection events, and debugging outputs.

zora status

Checks your active license verification status, hardware machine binding hash, and backend server connectivity.

zora uninstall

Safely terminates all background services, removes application files, and wipes cached licensing tokens cleanly.

Voice Interaction & Multilingual Fluency

Zora AI supports natural, spontaneous conversation across multiple languages simultaneously:

  • English: Full native conversation with standard voice assistant capabilities.
  • Bangla: Natural Bengali conversational idioms, friendly tones ("ki koro", "kemon acho").
  • Hindi: Fluent Hindi conversational understanding and response.

Barge-in Support: You do not need to wait for Zora to finish speaking. Simply start talking and the assistant will immediately pause and listen to your new command.

Desktop OS Automation

Zora AI possesses deep access to Windows system primitives to carry out actions autonomously:

  • Application Launching: "Open Chrome", "Launch VS Code", "Open Notepad".
  • Media & Audio Controls: Adjust master volume, mute, skip media tracks.
  • Screen Vision: Analyze active desktop windows and inspect multi-monitor setups.
  • Sleep & Silent Mode: Put Zora into quiet standby mode whenever you need uninterrupted focus.

Troubleshooting & FAQs

Common resolutions for setup questions:

  • Microphone not detected: Ensure Windows Settings → Privacy & Security → Microphone has permission enabled for Desktop Apps.
  • License Revoked: Contact Neon or verify your key in the Admin Console.

Privacy Policy

Last updated: October 2026. Your privacy and voice confidentiality are foundational.

1. Realtime Ephemeral Audio Processing

Zora AI processes microphone audio streams purely in real-time memory buffers. Audio data is streamed exclusively via encrypted bi-directional WebSockets/WebRTC directly to the neural inference session. Your voice recordings are never stored, saved to disk, recorded, or sold to third parties.

2. Local Device Permissions

To provide desktop assistance, Zora AI requests local operating system permissions strictly for executing requested user tasks (e.g., controlling volume, launching applications, capturing screenshots when explicitly asked). All system automation occurs locally on your machine.

3. Cryptographic License Verification

When you register a license key, a non-reversible cryptographic machine hash is validated against our Cloudflare edge directory to prevent unauthorized replication. No personal biometric or file data is included in this verification.

4. User Rights & Data Deletion

You may uninstall Zora AI at any time by executing zora uninstall in your terminal. This immediately purges all configuration files, tokens, and local cache from your PC.
